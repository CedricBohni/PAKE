fapake · interactive walkthrough

Log in with a password that's almost right

Fuzzy aPAKE lets a client and a server agree on a shared key when the password is close enough (here: at most one bit wrong). The server never stores the password, and neither side learns which bits were wrong.

1

Registration

server

The server picks a random secret k and splits it into 8 Shamir shares; any 6 of them rebuild k. For every password bit it stores a pair of slots: the real share goes in the slot matching the bit, a random decoy in the other. Values are stored as powers gx, so the file holds no password and no usable secret.

2

Fresh mask for this login

server

For each login the server draws a new secret r, splits it the same way and multiplies gri into both slots of pair i. The shared secret becomes K = gk+r, different every time. The server encrypts the masked pairs and gpw under K and sends the ciphertext.

3

Oblivious transfer

client ⇄ server

For each bit, the client fetches one slot using its own password bit. Oblivious transfer guarantees the server can't tell which slot was taken (it only sees a random-looking v), and the client learns nothing about the other slot. A correct bit gets the real share; a wrong bit silently gets the decoy.

4

Robust reconstruction

client

The client doesn't know which shares are decoys, so it tries every set of 6 out of 8 (28 sets) and interpolates each one. Sets made only of real shares all agree on K. With one wrong bit, 7 sets still agree. That majority is the error correction.

5

Checks and session key

client

The client decrypts the server's message with its K, checks that the registered password is within distance 1 of its own, and that the shares it received match the encrypted ones (catching a cheating server). On any failure it outputs a random key, so a wrong password looks like a right one until the key is used.

Every value on this page is computed by the project's own Python package, running in your browser via Pyodide.

Demo group values are tiny on purpose so you can read them. They offer no security.
